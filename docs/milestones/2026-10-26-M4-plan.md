## Docs checked (2026-10-26)
- **The MCP spec:** 2026-07-28 is still the current revision. Its authorization section applies to HTTP transports; a stdio server "SHOULD NOT follow this specification, and instead retrieve credentials from the environment", which is what this server does. Remote use: the server is an OAuth 2.1 resource server, publishes Protected Resource Metadata (RFC 9728), checks each token's audience (RFC 8707), and "MUST NOT accept or transit any other tokens", so no token passthrough to catalog-api.
- **SEP-2145** ("Standardize `tools/call` failure reporting") is still open and in review.
- **npm:** `@modelcontextprotocol/server` and `/client` are still 2.4.0; Inspector is still 2.12.0. No change to ADR-0002.
- **GitHub Actions:** `actions/checkout` v7.0.1 and `actions/setup-node` v7.1.0 are the latest; `ci.yml`'s `@v7` covers both.
- **gitleaks:** v8.30.1 (2026-03-21). winget has it from Gitleaks LLC; the Go module path is still `github.com/zricethezav/gitleaks/v8`.
- **MIT licence:** the standard text, as in product-catalog's `LICENSE`.
